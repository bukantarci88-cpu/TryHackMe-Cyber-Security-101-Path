## 🛡️ Lessons Learned

The **TryHackMe Cyber Security 101** path provided a practical foundation across key areas of cybersecurity through hands-on labs and security challenges.

* 🐧 **Linux Fundamentals** — Strengthened command-line skills, file management, permissions, processes, and system administration.
* 🪟 **Windows & Active Directory** — Developed an understanding of Windows administration, users, groups, authentication, and Active Directory fundamentals.
* 💻 **Command Line** — Practiced Bash and PowerShell commands for system interaction, troubleshooting, and security operations.
* 🌐 **Networking** — Built a stronger understanding of TCP/IP, OSI, DNS, HTTP/HTTPS, ports, protocols, and network communication.
* 🔐 **Cryptography** — Explored encryption, hashing, encoding, keys, certificates, and secure communication concepts.
* 🕵️ **Web Security** — Practiced identifying common web vulnerabilities and understanding how web applications can be attacked and defended.
* ⚔️ **Offensive Security** — Gained practical exposure to reconnaissance, enumeration, exploitation fundamentals, and security testing techniques.
* 🛡️ **Defensive Security** — Developed an understanding of monitoring, detection, incident response, logs, and defensive security controls.
* 🔍 **Security Operations** — Improved familiarity with investigating security events and applying structured approaches to cybersecurity incidents.
* 🧰 **Security Tools** — Practiced using common cybersecurity tools and command-line utilities in realistic lab environments.

### 

The path strengthened my ability to approach cybersecurity from both **offensive and defensive perspectives**, while connecting fundamental concepts with practical, hands-on security scenarios. It also provided a solid foundation for progressing toward more advanced areas such as **SOC operations, threat detection, penetration testing, digital forensics, and incident response**.
